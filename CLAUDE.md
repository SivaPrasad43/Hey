# Hey — project memory

Real-time chat app where every message carries a **feeling/mood** (happy, angry, sad, lovely). Solo project by SivaPrasad43; repo dormant 2024–2026, active again since Nov 2026 (conventional commits: `feat(chat): …`).

## Stack
- **Angular 21**, standalone components, signals, `input()/output()`, built-in control flow (`@if/@for`), **inline templates**, `ChangeDetectionStrategy.OnPush` on every component. Still zone-based (`provideZoneChangeDetection` in `main.ts`).
- **Firebase** via `@angular/fire` 21 (modular API): Auth (email/password) + Firestore with persistent multi-tab cache (memory cache under emulators). Project id `hey-chat-7ea1b`.
- **Tailwind CSS 4** (`@tailwindcss/postcss`, config lives in `src/styles.css` `@theme inline`) + **spartan-ng** (shadcn for Angular). Helm components are vendored in `libs/ui/*`, imported as `@spartan-ng/helm/<name>` (paths in `tsconfig.json`). Add new ones: `npx ng g @spartan-ng/cli:ui <name>`. Brain primitives come from `@spartan-ng/brain`.
- Icons: `@ng-icons/lucide`, registered centrally in `src/app/core/icons.ts` (`APP_ICONS`) — add new icons there.
- Dates: luxon. Fonts: Geist / Geist Mono. Emotion artwork: Fluent Emoji, generated by `npm run emotion-art` → `src/app/core/emotion-art.ts`.
- Tests: Karma + Jasmine (`*.spec.ts`, mostly pure-function tests next to the code). Node >= 22.12.

## Commands
- `npm start` (4200) · `npm run start:emu` (emulator config) · `npm test` · `npm run build` → `dist/hey-app/browser`
- `npm run emulators` (auth 9099, firestore 8080) · `npm run test:rules` runs `scripts/rules-smoke.mjs` against emulators
- `npm run deploy:rules` — the app depends on `firestore.rules` being deployed
- `.claude/launch.json`: `hey-dev` on port 4201, `hey-emu` on 4202
- Deploys: Vercel (`vercel.json`, SPA rewrite) and Firebase Hosting (`firebase.json`)

Routes (`app.routes.ts`): `/login`, `/register` (guestGuard); `/chat` shell (authGuard) with children `''`, `settings`, `help`, `:roomId`. All lazy-loaded; `withComponentInputBinding()` is on.

## Data model (Firestore)
- `users/{uid}`: displayName, email, avatarColor, online/lastSeen (60 s heartbeat, online if < 2.5 min), `lastRead.{roomId}`, favorites[], archived[], defaultMood
- `rooms/{roomId}`: name, type `group|dm`, members[], memberNames{}, createdBy, lastMessage{…}, updatedAt. DM id = two uids sorted joined by `_`. Shared room id `general` (`GENERAL_ROOM_ID`).
- `rooms/{id}/messages/{id}`: type `text|system`, text, senderId, senderName, mood, createdAt, reactions{uid→mood}, editedAt, deleted, clientId (optimistic send), replyTo{snapshot}
- `rooms/{id}/typing/{uid}`: name, at (ignored after 6 s)
- Pagination: `PAGE_SIZE = 30`, each page is a live stream over its createdAt range.

## Conventions / gotchas
- Mood colors are CSS vars (`--mood-*`, `--mood-*-fill`) in `styles.css`, mirrored as oklch values in `moods.ts` so specs can check contrast — **keep both in sync** when changing colors.
- Selected mood persisted in localStorage (`hey-mood`) via `ChatStateService`.
- Any new Firestore field/write path needs a matching `firestore.rules` change (rules use `onlyChanges([...])` allow-lists) and ideally a case in `rules-smoke.mjs`.
- Mobile UX matters: swipe-to-reply, long-press actions sheet, haptics.
- PWA: `@angular/service-worker` (`ngsw-config.json`, production builds only), `core/pwa.service.ts` (install prompt, iOS hint, update toast), manifest + icons in `public/` (maskable icons separate). SW is off in `ng serve`; test install/offline on a served `dist/` build.
- README's feature list is partly outdated (doesn't mention replies, reactions, receipts, emotion suggestions, settings).
- `firestore-debug.log` (~80 MB emulator log) sits in repo root; ignored by `*-debug.log`.
